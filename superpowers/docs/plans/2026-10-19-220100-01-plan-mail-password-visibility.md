# 邮箱密码显隐

**Goal:** 眼睛按钮可切换新输入及已保存邮箱密码的显示状态。
**Why planning is required:** 显式读取已加密保存的密码进入配置页，涉及凭据展示边界及异步返回时的账号隔离。
**Acceptance:** 仅现有受限小屋主框架 IPC 可主动读取当前账号凭据；普通快照不携带密码；不同邮箱或服务器不可读取旧密码；隐藏、收起或离开页面时清除只用于展示的已保存密码；提交不把展示值当作新密码；迟到请求不恢复明文。

### Outcome 1: 显式读取与界面
- Work: receiver 增加按账号和服务器校验的只读密码操作；沿用邮箱 IPC 主框架限制；密码框增加带可访问标签的眼睛按钮，分别处理本次输入和已保存值，异步响应按展示版本和账号隔离。
- Verify: 定向 receiver 和 renderer 测试覆盖未配置、匹配/不匹配账号、主动读取、不进入快照、显隐、取消晚返回、提交沿用。

### Outcome 2: 最终检查
- Work: 检查新动作调用方、错误输出、快照及保存路径；不读取实际用户凭据，不提交或推送。
- Verify: `node --test test/imap-mail.test.cjs test/mail-view.test.cjs test/imap-wire.test.cjs`、`npm run check`、`git diff --check`。桌面实测此前受自动审批服务 404 阻塞，本次不重试同一操作。

- `npm run check` 与 `git diff --check` 通过；邮箱界面 smoke 已补显隐断言，但受此前 Electron 启动/自动审批服务故障影响，本次未运行桌面实测。
