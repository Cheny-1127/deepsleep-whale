暂停接收后会怎样？

暂停的来源不再触发动作、计数或通知，进行中状态会清除，已有完成提醒保留。重新开启后从新事件开始接收，不补回暂停期间的记录。

逐项关闭后不再触发该事件的陪伴效果；结束和工具返回仍清理进行中状态，已有完成提醒保留。Cursor：打开总开关时创建或补齐全部 5 项配置，并备份、保留其他内容。总开关与逐项开关仅控制桌宠接收，不移除客户端 Hook。启动时读取实际配置，未接入的事件显示不可用。Codex：本页只控制接收，不修改配置或信任设置。

在微信里开始

  1. 发送 /projects 选择项目，再描述任务以新建对话。
  2. 继续桌面对话：发送 /chats，回复编号后直接聊；请保持 Codex 桌面端运行。
  3. 发送 /settings，选择用户信息，修改昵称、备注名和头像。
  4. 发送 /status 查任务状态，/stop 停止任务，/help 查看完整命令。

支持私聊文字；图片仅用于设置头像，暂不支持群聊和任务附件。已有桌面对话沿用原模型和权限。任务失败不会自动重跑，投递失败可单独重试。微信凭据与备注名加密保存在本机。
