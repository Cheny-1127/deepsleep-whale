暂停接收后会怎样？

暂停的来源不再触发动作、计数或通知，进行中状态会清除，已有完成提醒保留。重新开启后从新事件开始接收，不补回暂停期间的记录。

逐项关闭后不再触发该事件的陪伴效果；结束和工具返回仍清理进行中状态，已有完成提醒保留。Cursor：打开总开关时创建或补齐全部 5 项配置，并备份、保留其他内容。总开关与逐项开关仅控制桌宠接收，不移除客户端 Hook。启动时读取实际配置，未接入的事件显示不可用。Codex：本页只控制接收，不修改配置或信任设置。

TAKE YOUR PROJECT WITH YOU

微信接入

出门后，发条消息让本机客户端帮你排查。

未连接

扫码连接即可。沿用本机客户端的登录与配置，在微信里选择项目、新建或继续已有对话。电脑需保持开机联网。

连接微信

扫码绑定机器人账号后，用微信给它发送 /projects。

微信凭据加密保存在本机。支持私聊文字，暂不支持群聊和附件。

在微信里开始

  1. 发送 /projects 查看项目，回复数字（如 1）选择。
  2. 直接描述问题，会在所选项目新建对话。
  3. 继续桌面已有对话：发送 /chats，回复数字选择后直接聊。

选择桌面对话后，消息原样交给 Codex，沿用该会话的模型和权限，完成后回传本轮回复。请保持 Codex 桌面端运行。列表可回复“下一页”翻页；/new 新建对话，/clients 选择客户端。

客户端管理（可选） · 默认使用本机 Codex

可启用多个客户端。由上至下为优先级，新对话默认使用第一个已启用客户端；不会因任务失败自动切换账号重跑。无需填写模型 API Key。
